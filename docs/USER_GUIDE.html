Fieldwise: how to use it

A short, visual guide for everyone who uses Fieldwise. It keeps your field team on the map and your sales pipeline in one place. Find your role below: Employee (the app on your phone), Manager (your team, on the web) or Admin (setup and running the system, on the web). Each feature shows what it does, how to use it in a few taps, and, where it helps, a flow chart.

EveryoneManager and aboveAdmin only
Employee (field team): uses the phone app. Activate it once with the PIN from your admin, then it opens straight on Check in.
Manager, Admin, MD: use the web version in a browser (email, password). Setup and admin work are not in the phone app unless your admin gives a manager PIN.
